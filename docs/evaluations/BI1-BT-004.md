## Behavior in plain English

`/health/live` is what a Kubernetes / App Service liveness probe hits: it returns 200 whenever the process is responsive, no DB call, no auth. `/health/ready` is what a readiness probe hits: it returns 200 only when the database is reachable, which means migrations have run and connection pooling is up. Both endpoints are `[AllowAnonymous]` and outside the JWT-protected surface.

For production safety, `app.UseHsts()` is enabled in non-Development environments so any HTTPS response carries the `Strict-Transport-Security` header. The development environment retains the HTTP listener so curl + the frontend dev server work without certificate hassle.
