### Finding F1 — "may" in L2-061

- **Where:** `./docs/specs/L2.md` L2-061 (Audit log retention).
- **What:** AC 1 ended with "rows older than 365 days **may** be archived or removed per environment policy" — a hedge word not permitted by R1's "No ambiguous language" rule (use "must" or "shall" only).
- **Fix:** rewrote the AC to use "must" for the 90-day query guarantee and "shall" for the >365-day archive/removal allowance.

### Finding F2 — no explicit output-encoding L2

- **Where:** `./docs/specs/L2.md`.
- **What:** R2 criterion 8 enumerates "output encoding" among required OWASP-relevant L2s. The spec had input validation (L2-047/048) but no requirement constraining how user-supplied content is rendered in templates (XSS surface).
- **Fix:** broadened L1-016's title and text to "Input validation and output safety"; added **L2-066: Output encoding (XSS protection)** tracing to L1-016 with ACs covering Angular's safe interpolation and prohibition of `bypassSecurityTrust*` on user input.

### Finding F3 — no explicit dependency-hygiene L2

- **Where:** `./docs/specs/L2.md`.
- **What:** R2 criterion 8 also enumerates "dependency hygiene". The spec had no requirement around third-party package vulnerability surfacing.
- **Fix:** added a new **L1-024: Dependency hygiene** and **L2-067: Vulnerability scanning of dependencies** tracing to it. L2-067 requires the CI pipeline to fail the build on `High`/`Critical` advisories from `dotnet list package --vulnerable` and `npm audit`.
