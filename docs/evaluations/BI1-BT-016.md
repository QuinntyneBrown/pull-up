## Behavior

Handler reads the current user (host), creates an `Event` (Scheduled status, `UpdatedAt = now`), adds a host self-RSVP with status `Going` (L2-019), and for any `inviteeEmails` does a single round-trip lookup (`db.Users.Where(u => normalized.Contains(u.Email))`) before adding one `Invitation` per email — known users get `UserId` set; email-only invites leave it null. All in one `SaveChangesAsync`. Validator enforces title 1–120, location 1–200, description ≤ 2000, date ≥ today (UTC), end > start when supplied, per-invitee email syntax. `[AuditedAction("EVENT_CREATED")]`.
