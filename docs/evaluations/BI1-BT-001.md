### One design correction during implementation

The first iteration of `IAuthorizationHandler<TRequest>` constrained `TRequest` to `IAuthorizationRequirement`, which made the open-generic `AuthorizationBehavior<TRequest, TResponse>` (with its `where TRequest : notnull` constraint) fail to compile when referring to `IAuthorizationHandler<TRequest>` in its field type. Resolution: dropped the constraint on `IAuthorizationHandler<TRequest>`; the marker interface stays as documentation at the call site. This keeps the behavior's open-generic registration trivial while preserving the "this command needs auth" signal on the request types that opt in.
