## Behavior

`SetRsvpAuthorizationHandler` allows host OR active-invitation (and passes when the event is missing so the handler can throw 404). Handler loads the event, rejects with `EventAlreadyPassedException` → 409 if `StartsAtUtc <= now`, then upserts the `Rsvp` row via `Rsvp.Create` or `rsvp.Update`. After save, if the caller isn't the host, fans out `DispatchInvitationNotificationCommand(RsvpChanged)` to the host — the dispatcher itself gates on the host's `RsvpChanges` preference.

Validator enforces the status string parses to `RsvpStatus` and that the note is ≤ 500 chars. `[AuditedAction("EVENT_RSVP_SET")]`.
