# FI1 — FT-005 App-shell components

## What shipped

`projects/components/src/lib/`:

- `nav-item.ts` — shared `NavItem` interface (`route`, `icon`, `label`); primitives only.
- `app-bar/app-bar.component.{ts,html,scss}` — `pu-app-bar` with `title` input and two `<ng-content>` slots (`[appBarLeading]`, `[appBarTrailing]`). Material 3 surface colors via `--mat-sys-*`.
- `bottom-nav-bar/bottom-nav-bar.component.{ts,html,scss}` — `pu-bottom-nav-bar` taking `items: ReadonlyArray<NavItem>` + `activeRoute: string | null`. Renders `<a [routerLink]>` per item with `mat-icon` + label. `:host` hidden via `@media (min-width: 768px) { display: none }`.
- `nav-rail/nav-rail.component.{ts,html,scss}` — `pu-nav-rail` with the same inputs, vertical layout. `:host` hidden by default; shown at `@media (min-width: 768px)`. Active item gets a `--mat-sys-secondary-container` pill behind the icon (Material 3 nav-rail pattern).

`public-api.ts` re-exports the three components + `NavItem` type.

## Library placement

All artifacts in `projects/components/src/lib/`. No imports from `api` or `domain` — only `@angular/material/icon` and `@angular/router/RouterLink`. Verified by repository-root grep.
