## Behavior

Handler normalizes the email, looks up the user, and on a match generates a 256-bit raw token (HMAC-hashed via the BT-005 `ITokenHasher`) with a 60-minute expiry. Row goes to `PasswordResetTokens`; the raw value goes to `IEmailSender.SendPasswordResetEmailAsync`. On unknown email it returns silently. Either way the controller returns **HTTP 202 Accepted** — the response is identical so the endpoint cannot enumerate accounts (L2-008). The command is `[AuditedAction("PASSWORD_RESET_REQUESTED")]` so the audit trail captures every attempt (L2-010).

`LoggingEmailSender` is the MVP's deferred-integration logging stand-in per BP1 §9. It logs only the recipient email + expiry — never the raw token — honoring L2-044.
