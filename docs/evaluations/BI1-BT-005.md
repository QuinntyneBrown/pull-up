## Design notes for downstream slices

- **Refresh-token lookup pattern** (used by BT-008 / BT-009 / BT-011): given a raw token, the handler computes `tokenHasher.Hash(raw)` and queries `RefreshTokens` by `TokenHash` (unique index). No table scan, no plaintext comparison.
- **Rotation pattern** (BT-008): `var old = lookup(raw); old.Revoke(now, replacedBy: new.Id); db.RefreshTokens.Add(new);` — both in the same `SaveChangesAsync`.
- **All-revoke pattern** (BT-011 password reset, BT-015 account delete): `db.RefreshTokens.Where(r => r.UserId == userId && r.RevokedAt == null).ExecuteUpdate(s => s.SetProperty(r => r.RevokedAt, now))`.
