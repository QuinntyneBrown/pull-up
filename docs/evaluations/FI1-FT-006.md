# FI1 — FT-006 Event card + RSVP avatar stack

## What shipped

`projects/components/src/lib/`:

- `event-card/event-card.component.{ts,html,scss}` — `pu-event-card` with **primitive inputs only**: `title: string`, `startsAtUtc: Date`, `location: string`, `isHost: boolean`, `myRsvpStatus: 'Going' | 'Maybe' | 'CantGo' | null`. Renders title + host badge, date/time (via `DatePipe`) + location with icons, and a tone-colored RSVP badge in the footer when set. The `EventCardRsvpStatus` type is exported so consuming domain pages get type safety when mapping from `EventSummary.myRsvpStatus`.
- `rsvp-avatar-stack/rsvp-avatar-stack.component.{ts,html,scss}` — `pu-rsvp-avatar-stack` with primitive inputs `entries: ReadonlyArray<{ initials: string; tone: 'primary' | 'secondary' | 'tertiary' }>` + `maxVisible: number = 4`. Renders M3 container-tone discs with `-8px` overlap; `+N` overflow badge when entries exceed `maxVisible`.

`public-api.ts` re-exports both components plus the `EventCardRsvpStatus`, `AvatarEntry`, and `AvatarTone` type aliases.

## Library placement

All artifacts in `projects/components/src/lib/`. No imports from `api` or `domain` — only `@angular/common/DatePipe` and `@angular/material/icon`. Verified by grep (no matches for `from 'api'` or `from 'domain'`).

This is the F1 fix from FT2 in action: the `myRsvpStatus` input is a string union literal that **mirrors** the api `RsvpStatus` value space rather than importing it, keeping `components` free of api dependencies.
