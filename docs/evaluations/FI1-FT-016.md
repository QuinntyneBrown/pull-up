# FI1 — FT-016 Event create page

## What shipped

- `EventCreatePageComponent` (new, `domain` library):
  - Route `/events/new`.
  - Reactive form: title (required, ≤200), date (`mat-datepicker`, min = today), time, location (required), description, `allowPlusOne` toggle, `showGuestList` toggle.
  - Chip-input for invitees (email validation; Enter/Add button appends; ×-chip removes pending invitee).
  - On submit: calls `EVENTS_SERVICE.create(...)`, then `addInvitee` for each pending invitee, then navigates to `/events/:id`.
- `app.routes.ts` updated: `/events/new` added before `/events/:id` (required for correct route matching).
- `public-api.ts` updated to export `EventCreatePageComponent`.
