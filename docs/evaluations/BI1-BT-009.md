## Behavior

Handler hashes the supplied raw refresh token via the BT-005 `ITokenHasher`, looks it up by `TokenHash`, and revokes it if present and active. Unknown / already-revoked tokens are **silently treated as success** so the endpoint is idempotent and does not leak token validity. Command is annotated `[AuditedAction("USER_SIGNED_OUT")]` so the audit trail captures every sign-out attempt (success path only here — the handler does not throw on unknown tokens).
