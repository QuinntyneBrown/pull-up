# FI1 — FT-017 Event detail page (read + RSVP)

## What shipped

- `EventDetailPageComponent` (new, `domain` library):
  - Route `/events/:id`.
  - Fetches `EVENTS_SERVICE.get(id)` on mount; shows loading skeleton then the detail view.
  - Hero card: `detail-hero` section with `detail-title`, date/time, location.
  - Host card: avatar initials, full name, display name.
  - RSVP segmented button (`SegmentedButtonComponent`): Going / Maybe / Can't Go — hidden for past/cancelled events; calls `EVENTS_SERVICE.setRsvp(...)` on selection.

  - Description card (shown when non-empty).
  - Host-only action section: "Edit" link to `/events/:id/edit`.
- `app.routes.ts` updated: `/events/:id` route registered; ordering relative to `/events/new` and `/events/:id/edit` is correct.
- `public-api.ts` updated to export `EventDetailPageComponent`.
