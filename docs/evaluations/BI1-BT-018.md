## Behavior

Handler loads the event, returns 404 if absent, then authorizes: caller must be the host **or** carry an active (non-removed) `Invitation`. Otherwise it throws `NotAuthorizedException` → HTTP 403 (existing mapping). Response carries the event fields, the host's name + email, aggregate RSVP counts (going / maybe / can't go), the caller's own RSVP status (or null), and — when caller is host OR `ShowGuestList=true` — a flat guest list per `Invitation` (resolving the user's name from `Users` when known, exposing the per-guest RSVP + note).

`AsNoTracking()` throughout per the L2-058/059 performance budget.
