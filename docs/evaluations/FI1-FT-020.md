# FI1 — FT-020 Responsive viewport spec

## What shipped

- `e2e/responsive.spec.ts` (new):
  - Uses `test.use({ viewport })` inside `test.describe` to set 360 × 780, 768 × 1024, and 1440 × 900 viewports.
  - For each of the three widths, runs four tests covering the four main pages.
  - All API calls are mocked via `page.route(...)` — no live backend required.

## Pages and assertions

| Page | Key assertions |
|------|---------------|
| `/home` | `home-filter-strip` and `home-create-fab` visible at every viewport |
| `/events/:id` | `detail-hero` and `detail-title` visible at every viewport |
| `/events/new` | `create-title` and `create-submit` visible at every viewport |
| `/profile` | `profile-fullname` visible at every viewport |
