## Behavior

The handler hashes the supplied raw refresh token via the BT-005 `ITokenHasher`, locates the row by `TokenHash` (unique index → O(1)), and rejects with `InvalidRefreshTokenException` when the row is missing, revoked, or expired. On a hit, it issues a brand-new access + refresh pair, marks the old refresh row revoked with `ReplacedByTokenId = newRefresh.Id` for forensics, persists the new row, and returns both raw tokens.

The command is annotated `[AuditedAction("ACCESS_TOKEN_REFRESHED")]` so success and failure rows fall out of the existing `AuditingBehavior` automatically.
