# FI1 — FT-015 Home page full event list

## What shipped

- `HomePageComponent` (replaced from MF1 welcome card stub):
  - Calls `EVENTS_SERVICE.list()` on mount; shows `LoadingSkeletonComponent` while pending.
  - Groups results into "This week", "Later this month", "Next month", and "Past" buckets.
  - `FilterStripComponent` (All / Hosting / Invited / Past) re-fetches with the selected scope.
  - `EventCardComponent` per row with title, date, location, and host/RSVP indicator.
  - `EmptyStateComponent` when no events match the active filter.
  - `ErrorStateComponent` on API failure with a Retry button.
  - FAB (`home-create-fab`) navigates to `/events/new`.

## Acceptance test (Playwright POM)

- `e2e/home-list-flow.spec.ts` + `e2e/pages/home-page.ts` — scenarios × 2 projects = **4 tests**, all passing.

The tests verify:
1. **Populated list:** mocked `/api/events` returns events grouped into buckets; cards render in each group.
2. **Empty state:** list returns no events; empty-state component is visible.
3. **Filter chip:** switching chip to "Hosting" re-fetches and renders the host filter view.
4. **Create FAB:** tapping FAB navigates to `/events/new`.
