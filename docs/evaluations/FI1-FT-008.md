# FI1 — FT-008 Interactive components

## What shipped

`projects/components/src/lib/`:

- `filter-strip/filter-strip.component.{ts,html,scss}` — `pu-filter-strip` with inputs `chips: ReadonlyArray<FilterChip>` (`{ key, label }`) + `selectedKey: string | null` and `(chipChange) = EventEmitter<string>`. Horizontal scroll, `role="tablist"` + `aria-selected` per chip. Selected chip uses `--mat-sys-secondary-container`. Per-chip `data-testid="filter-chip-{key}"` for Playwright.
- `segmented-button/segmented-button.component.{ts,html,scss}` — `pu-segmented-button` with inputs `options: ReadonlyArray<SegmentedOption>` (`{ value, label, icon? }`) + `selected: string | null` + `ariaLabel: string` and `(selectionChange) = EventEmitter<string>`. M3 segmented control pattern: rounded pill, dividers, secondary-container highlight on selected. `role="radiogroup"` + `role="radio"` per option. `data-testid="segmented-{value}"` per option.

`public-api.ts` re-exports both components + `FilterChip` and `SegmentedOption` types.
