# Support

## Getting help

Use GitHub Issues for bugs and feature requests:

https://github.com/QuinntyneBrown/pull-up/issues

Before opening a new issue:

1. Search existing issues to avoid duplicates.
2. Include clear reproduction steps.
3. Include environment details (`dotnet --info`, `node --version`, browser).

## Documentation

- `README.md` for project overview and quick start.
- `docs/runbooks/backend.md` for API setup and operations.
- `docs/runbooks/frontend.md` for frontend setup and testing.

## Security issues

For vulnerabilities, follow [SECURITY.md](SECURITY.md). Do not file public issues.
