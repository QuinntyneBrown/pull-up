# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please **do not** disclose vulnerabilities publicly in issues, discussions, or pull requests.

Use GitHub Security Advisories:

1. Go to the Security tab for this repository.
2. Click **Report a vulnerability**.
3. Provide impact, reproduction steps, and any proposed mitigation.

Direct link:

https://github.com/QuinntyneBrown/pull-up/security/advisories/new

## What to include

- Affected component(s) and file paths
- Step-by-step reproduction
- Impact assessment (confidentiality, integrity, availability)
- Any temporary workaround

We will acknowledge receipt and coordinate remediation and disclosure timing.
